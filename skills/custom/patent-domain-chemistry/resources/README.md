# patent-domain-chemistry — 资源目录（可选）

- **通用**《专利审查指南》、跨领域样板 PDF：优先放在 **`patent-cn-core/resources/`**，避免重复占空间。  
- 本目录可放**仅化学案**才用的补充 PDF（如特定领域授权文本）；模型路径示例：  
  `skills/public/patent-domain-chemistry/resources/你的文件.pdf`  
  容器内一般为 `/mnt/skills/public/patent-domain-chemistry/resources/...`。

对内打包时与项目一起复制本目录即可；公开 Git 下建议用本目录 `.gitignore` 忽略 `*.pdf`（与 core 一致）。
