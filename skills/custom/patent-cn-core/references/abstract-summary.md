# 说明书摘要（中文发明 / 实用新型）

**效力**：下表要点转述自《专利审查指南》**第一部分**有关**说明书摘要**的形式审查（发明见约 **4.5** 节，实用新型见**实用新型初步审查**中**说明书摘要**等对应节）。**章次与标点以你手头现行官方 PDF 为准**，定稿前请代理人核对原文。

---

## 指南要点（工作用）

| 项目 | 要求（要点转述） |
|------|------------------|
| **内容** | 写明**发明名称**和**所属技术领域**，**清楚反映**所要解决的**技术问题**、解决该问题的**技术方案的要点**以及**主要用途**。 |
| **实用新型侧重** | 尤其应写明相对背景技术在**形状、构造**上作出改进的技术特征；**不得**写成广告或单纯功能性产品介绍。 |
| **标题** | 摘要文字部分**不得使用标题**（勿设「一、摘要」等小节标题；正文起笔可直接从名称/领域写起，或按所内固定起句，但**不要**用 Markdown `## 摘要` 当摘要正文结构）。 |
| **字数** | 摘要文字部分**（包括标点符号）不得超过 300 个字**。超出应删节。 |
| **用语** | **不得**使用商业性宣传用语；审查中可删。 |
| **化学式** | 摘要中可以包含**最能说明发明的化学式**，该化学式可视为摘要附图（依指南具体规定）。 |
| **摘要附图** | 说明书有附图的，应**指定一幅**最能说明技术方案**主要技术特征**的附图作摘要附图，并在请求书中写图号（程序性事项由代理人处理，撰稿时可备注「建议摘要附图：图X」）。附图缩小至约 4cm×6cm 仍应可辨细节（形式要求）。 |

---

## 模型输出约定（避免漏摘要）

- 用户要求「生成专利说明书 / 申请文件 / 全文」时，除**说明书正文六块**与**权利要求书**外，须**单独输出「# 摘要」作为一级标题**，标题下紧跟摘要正文（连续段落，**内部不设小标题**），并**自检字数 ≤300（含标点）**。  
- **摘要必须放在全文最开头**，权利要求书**紧跟在摘要之后**（在「1. 技术领域」之前）。作为递交件，摘要与权利要求书位于正文六部分之前。**禁止**将摘要或权利要求书放在具体实施方式之后。撰写过程中可以先在心里拟好内容，但**最终输出时摘要和权利要求书必须在最前面**。
- 摘要应能从**独立权利要求**与**发明内容**中提炼，**不引入**说明书未记载的新特征。  
- 若用户仅改某一节且未要摘要，可不强行输出；若用户抱怨**没有摘要**，则**优先**补写摘要并满足上表。
