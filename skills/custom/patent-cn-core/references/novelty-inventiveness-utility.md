# 新颖性、创造性、实用性（论证框架与自查要点）

**对应指南**：请在现行《专利审查指南》**实质审查**部分检索**新颖性**、**创造性**、**实用性**各章。下文为**论证整理用的框架与提醒**，**不是**审查结论，**不能**替代代理师对对比文件与最接近现有技术的认定。

---

## 新颖性（整理材料时）

- 把握「**单独对比**」思路：技术方案与**一篇**现有技术对比是否被公开（含隐含公开等复杂情形由代理师判断）。
- 协助用户时：列出**权利要求特征**与**对比文件相应记载**的**对应关系表**，标出「已公开 / 未公开 / 存疑」；存疑处注明「待代理人核实」。
- **不得**编造对比文件未记载的内容；用户未提供对比文件全文时，只基于用户摘录整理逻辑。

## 创造性（整理材料时）

- 常用「**三步法**」叙述框架（具体是否适用、如何认定最接近现有技术由代理师决定）：
  1. 确定最接近的现有技术；  
  2. 确定区别特征和实际解决的技术问题；  
  3. 判断要求保护的发明对本领域技术人员是否显而易见。  
- 你的输出侧重：**区别特征列表**、**技术问题表述草稿**、**技术效果**与**公知常识/对比文件组合**的**假设性**讨论，并反复强调「是否显而易见以审查员/复审结论为准」。
- **实用新型**与发明在创造性标准上**可能不同**，涉及实用新型案时提醒代理人**单独核对指南中实用新型相关规定**。

## 实用性（整理材料时）

- 关注是否明显**违背自然规律**、是否**无积极效果**等指南中的典型情形（以原文为准）。  
- 勿对「能否制造或使用」作终局认定；可列**需说明书或实验支持**的要点。

## OA / 审查意见答复（协作方式）

- 先**逐条**归纳审查意见引用法条与事实。  
- 再区分：**事实争议**（对比文件理解）与**法律适用**（由代理师主导）。  
- 建议修改权利要求时，同步检查**是否超范围**（见 `amendment-and-procedural.md`）。
