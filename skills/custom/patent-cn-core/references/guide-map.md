# 《专利审查指南》参阅映射（本目录）

**效力说明**：以下均为**撰写与自查辅助要点**，**不构成**对现行《专利审查指南》及配套规定的引用或替代。具体条文、款号、标点及例外情形**必须以国家知识产权局公开发布的现行有效文本为准**。代理师定稿前应核对官方 PDF / 法规数据库。

## 与指南「大致位置」的对应（目录级）

> 指南会修订，**章次与编号以你手头现行版目录为准**。下表仅帮助在官方文本中**定位到哪一章找原文**。


| 主题               | 常见检索入口（名称级）                               |
| ---------------- | ----------------------------------------- |
| 说明书、权利要求的形式与实质要求 | 指南 **第二部分** 实质审查中关于**说明书和权利要求书**的章节       |
| 新颖性              | 指南 **第二部分** 中**新颖性**章节                    |
| 创造性              | 指南 **第二部分** 中**创造性**章节                    |
| 实用性              | 指南 **第二部分** 中**实用性**章节                    |
| 申请文件的修改、分案等      | 指南中**申请的修改**、**分案申请**等程序与实体结合章节（以现行版目录为准） |


## 使用方式

1. 用本目录要点做**自查清单**与**答复提纲**。
2. 需要引用**原文**或**款号**时，打开用户或事务所提供的**官方指南 PDF** 逐字核对。
3. 不要在对外文稿中编造「第××条」——若代理师未提供条文，只写原则并标注「请核对指南原文」。
