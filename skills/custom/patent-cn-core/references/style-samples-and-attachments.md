# 官方指南与样板 PDF（可选附件）— 怎么用、要不要放进 skill 目录

本文件说明：**《专利审查指南》**、**已授权专利 PDF** 放在哪、如何兼顾「模型可读」「项目打包」与「仓库体积」。

**约定**：`patent-cn-core/resources/samples/` 下 **已提交样板 PDF**（化学/机械/电学各若干），与下文表格一致；**《审查指南》** 仍建议自备至 `resources/专利审查指南.pdf`（见该目录 `.gitignore`）。各 **`patent-domain-*/resources/`** 可再放领域专用 PDF（默认整夹仍 ignore `*.pdf`，避免误提交大文件）。

---

## 1. 《专利审查指南》PDF

**放在 `patent-cn-core/resources/专利审查指南.pdf`**（或团队在 `resources/README.md` 中约定的固定名），便于本机/容器内 `read_file`。

| 考量 | 说明 |
|------|------|
| **体积与 Git** | 全文 PDF 通常数 MB～数十 MB；`resources/.gitignore` **仅忽略** `专利审查指南.pdf`，**不**忽略 `samples/**/*.pdf`。 |
| **对内打包** | 发 zip、打 Docker 镜像前把 PDF **拷进 `resources/`**，即可与项目/技能树一起交付。 |
| **版本** | **以国知局公开发布的现行有效文本为准**；逐字引用前用你手头的最新版 PDF 核对。 |
| **对外分发** | 仅拷贝 Git 的用户需**自行下载**指南到 `resources/`，或从内网制品包取得带 PDF 的 `resources/` 覆盖层。 |

**勿**长期把指南放在与 `SKILL.md` 同级旧路径；请迁到 `resources/`（见 `resources/README.md`）。

**模型使用方式**：若文件存在，可 `read_file` 容器路径如 `/mnt/skills/public/patent-cn-core/resources/专利审查指南.pdf`；若不存在，仅用 `references/*.md` 并提示核对官方 PDF。

---

## 2. 化学 / 机械 / 电学样板专利 PDF

- **通用样板**：集中在 **`patent-cn-core/resources/samples/{chemistry,mechanical,electrical}/`**（本仓库已预置，见下节表格）。  
- **领域专用**：可放在 **`patent-domain-*/resources/`**（该路径下 `*.pdf` 默认仍由各 skill 的 `.gitignore` 忽略，以免误提交）。  
- **《审查指南》全文**：自备至 `resources/专利审查指南.pdf`（见 `resources/.gitignore`）。

## 4. 小结

- **`resources/samples/`**：样板专利 **可随 Git 分发**，避免「skill 里写了案号却找不到文件」；样板优先为**可抽取文字层** PDF，便于离线批处理为 `.md` 全文参考。  
- **`专利审查指南.pdf`**：仍建议**本地/所内自备**，不强制进库。  
- **`references/*.md`**：通用规则；**`resources/`**：原文与样板 PDF——两者互补。
