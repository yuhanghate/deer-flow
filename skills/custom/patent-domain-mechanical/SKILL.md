# 专利撰写 — 机械领域

## 本 skill 解决什么

机械案的核心是**空间关系与附图一致性**：标号乱、名称混用、权利要求与图对不上，会在审查与侵权阶段放大问题。本 skill 优先保证**图—文—权项**可对齐。

**可选 PDF 附件**：通用资料见 `patent-cn-core/resources/`。若要从 PDF **抽取整篇正文或表格**，按需加载技能 **`pdf`**（`skills/public/pdf/SKILL.md`），与 `patent-cn-core` 中说明一致。

**摘要**：见 `patent-cn-core` 的「Step 2：摘要」；样板见 `patent-cn-core/resources/samples/mechanical/`。

**超长上下文**：`config.yaml` 中 `summarization` 启用时由平台自动压缩旧对话。若仍感到上下文紧张，先按 `patent-cn-core` 中「超长上下文与对话承接」输出《对话承接稿》，并**额外**保留本 skill 相关的构件—标号—名称对照、权利要求项号与装配/剖视叙述进度，再继续撰写。

## 工作流

1. 让用户明确（或从交底推断）**关键附图**：立体图、剖视图、爆炸图各承担什么信息；不确定则列出假设并请确认。
2. 建立**构件—标号—名称**对照表草案，全文沿用；发现同物异名时合并为一种称呼。
3. 具体实施方式：按**装配顺序**或**工作循环**写，每一步对应可写入权利要求的特征。
4. 权利要求：先列**结构特征 + 连接/位置关系**，再写成条文；**正式权利要求书**的**连续编号与顺序**（独立→从属、双主题不接 `##` 分节、10-16项、禁止点值罗列）见 `patent-cn-core` 的「Step 3：权利要求书」；功能性限定需指出说明书中的**具体实现段落**。
5. 方向用语（上下左右）一律**相对基准**（如相对机架、相对重力方向），避免绝对化歧义。
6. 交付文件默认 `docx`（中文专利优先），不要默认交付 `md`；若用户要 PDF，优先建议用 Word/WPS 打开 `docx` 后本机导出 PDF。

**章节顺序**：整篇撰写时章节顺序以 `patent-cn-core/SKILL.md` 的"强制输出顺序"为准，本 skill 只管领域内的撰写习惯和术语。

## 强约束（内部参考不外泄）

1. skill 内置样板公开号/路径仅供内部校准，禁止对用户展示。
2. 即使用户要求对比文献，也不得引用内置样板编号；仅可使用用户提供或运行时外部检索得到的文献。
3. 交付前自检：若出现 `CN` 号或内置样板路径，先改写为泛化表述（如“现有技术”）再输出。

## 发明内容（与 core 一致）

说明书第三节须含**技术问题、技术方案（含优选层次，不另立从属技术方案节）、有益效果**（≥6条，**可多段分述**，无具体数值）；**每个核心技术特征后须写原理/作用/效果**——见 `patent-cn-core` 的「Step 5：发明内容」。

**实施例标题**：`实施例1：` **单独成行**（全角「：」），勿用 `### 实施例1：副标题` ——见 `patent-cn-core` 的「Step 7：具体实施方式」中「实施例/对比例标题格式」。

## 附图与说明书

同一部件在全文与附图中的**标号一致**；说明书中首次出现构件时建立「标号—名称」对应。

爆炸图、剖视图要说清**装配关系、运动方向、配合面**；避免仅有外观无功能结构。

## 具体实施方式（与 core 配合）

**实施例前准备**（与 `patent-cn-core` 的「Step 7.1」配合）：机械案须在实施例1之前以段落格式补充：
- **材料/标准件信息**：集中整理涉及的钢材牌号、标准件型号（如GB/T 5782螺栓）、表面处理工艺等
- **测试/检验方法**：统一归纳尺寸检测、力学性能测试、硬度/粗糙度测量等方法，交底已给出标准号的照录，未给出的写「标准号待补」

**对比总结**（与 `patent-cn-core` 的「Step 7.4」配合）：所有实施例和对比例写完后，须增加对比分析段落，将实施例与对比例的测试结果逐项对照（如承载能力、寿命、加工效率等），对应到有益效果。

**待审核辅助**（与 `patent-cn-core` 的「待审核」配合）：机械案特别关注：
- 构件标号在全文、附图说明、权项中是否一致
- 方向用语（上下左右）是否有明确基准
- 公差/间隙/配合的数值范围是否有实施例支撑
- 功能性限定是否在说明书中有具体结构实现
- **点值转范围**：交底中若给出多组离散工艺参数（如转速、温度、负载等），检查是否已概括为范围值；机械案以结构限定为主，参数范围为辅，若交底仅给了1-2个点值就概括为宽范围，需提醒代理人注意支持性

## 权利要求（机械常见写法）

独立项：用可观察的**形状、构造、位置、连接**限定；少用「合适的」「适当的」除非代理师有策略考虑。

从属项：下钻材料、尺寸、表面处理、配合形式、优选结构细节。

若采用功能性限定，提醒代理人核对**说明书支持**是否充分。

## 简短示例（特征列举 → 权项）

**示例（内部草稿形态）：**

特征列表：基座（10）；支架（20）一端与基座铰接；锁扣（30）在闭合位置与支架卡合……

再改写成一条装置权利要求条文（由代理师最终定稿用语）。

## 不要做的事

虚构附图、编造尺寸与公差计算结果、捏造现有技术文献内容。
泄露 skill 内置样板的公开号、文件路径或引用片段。
